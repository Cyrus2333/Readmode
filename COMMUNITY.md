# Readmode Community Edition

Readmode Community Edition is the open-source, local-first core of Readmode.
It provides Markdown reading and HTML document/prototype preview in Chrome.

## Editions

- **Community Edition** — the source in this repository, distributed under the MIT License.
- **Official Store Edition** — the Chrome Web Store build, which contains the Community core plus proprietary, optional Readmode Pro functionality.

The official Store Edition is built in a private release environment. Its Pro implementation is not part of this repository. Client-side code shipped to a browser can still be inspected by the browser owner; the commercial boundary is source distribution and licensing, not a promise of impossible reverse engineering.
