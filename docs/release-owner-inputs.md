# 发布前仍需产品负责人完成的事项

这些事项不能由代码自动代替，完成后才可以把预发布版切换成公开售卖版：

1. 提供官网、支持入口和第三方支付 checkout URL。
2. 确认销售地区、货币、Pro 价格、授权规则和退款规则。
3. 在项目目录外生成并备份生产许可证私钥；发布包只包含公钥。
4. 用最终 Chrome 版本截取 3–5 张无敏感信息的商店截图。
5. 在干净 Chrome 配置文件完成本地 Markdown、在线鉴权附件、HTML 安全预览、原始运行、设置和许可证回归。
6. 用 `npm run release:check` 确认没有预发布占位内容后，才接受真实订单。

当前没有配置真实支付，因此插件设置页不会显示购买按钮；这不是故障，而是防止误收费的安全闸门。
