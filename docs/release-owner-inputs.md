# Readmode 发布负责人输入表

## 当前免费开源发布

当前版本不需要支付平台、Pro 价格、许可证密钥或商业销售主体。公开发布前需要完成：

1. 确认 GitHub 仓库和 GitHub Pages 可访问；
2. 使用最终 Chrome 版本完成本地 Markdown、在线鉴权附件、HTML 安全预览和原始运行回归；
3. 确认最终截图不含敏感内容；
4. 用 `npm run check`、`npm run preflight` 和 `npm run release:check` 完成检查；
5. 上传 `dist/readmode-0.3.3-community.zip` 到 Chrome Web Store。

## 未来商业化时再处理

如果未来引入收费功能，再单独确认销售主体、支付平台、价格、退款规则和生产许可证。当前版本不接受真实付款。
