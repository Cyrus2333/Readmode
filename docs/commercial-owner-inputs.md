# Readmode 后续商业化负责人输入表

> 当前版本先保持免费开源。本文件仅作为未来重新评估商业化时的备忘，不是当前发布阻塞项。

如果未来确实出现稳定的付费需求，再确认：

| 项目 | 需要提供的值 |
| --- | --- |
| 销售主体 | 个人或公司、所在国家/地区 |
| 收款方式 | 支持的银行账户或支付平台 |
| 销售地区/货币 | 例如全球 / USD |
| Pro 价格 | 一次性授权或其他形式 |
| 授权规则 | 设备数量、版本范围和转移规则 |
| 退款规则 | 退款期限与退款后的授权处理 |
| 支持入口 | 邮箱或 issue tracker |

未来的接入原则：

- 不把支付密钥、Webhook 密钥或许可证私钥放进扩展；
- 不上传用户文档内容；
- 不以设备指纹作为授权前提；
- 先人工验证订单，再考虑自动化；
- 在实际收款前完成平台、税务、条款和退款流程确认。
