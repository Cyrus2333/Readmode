## Full description

Readmode is a free and open-source Chrome extension for reading Markdown files and previewing HTML documents and prototypes.

### Read Markdown files

- Open local `.md`, `.markdown`, `.mkd`, and `.mdx` files in a readable layout.
- Read Markdown attachments and authenticated document links opened in Chrome.
- Use a full-screen reading layout with a permanent left-side table of contents.
- View tables, task lists, blockquotes, alerts, images, and code blocks.
- Switch between light and dark reading themes.
- View the original source at any time.

### Preview HTML documents and prototypes

- Preserve the original HTML page layout and styles in a full-screen preview.
- Use a safe preview mode with scripts disabled by default.
- Run the original HTML only when you explicitly choose to do so.
- Keep HTML prototypes visually separate from Readmode's controls.

### Local-first and open source

Readmode processes documents in your browser and does not upload document contents to a Readmode server. Authenticated links are fetched using your existing browser session when you choose to preview them.

The source code is available under the MIT License. Readmode does not require an account, subscription, or payment to use its current features.

### How to use

1. Open a Markdown or HTML file in Chrome.
2. Click the Readmode extension icon, or use the context menu.
3. Choose the reading or preview action you need.
4. For local files, enable “Allow access to file URLs” in Chrome's extension details.

Readmode is designed for product managers, developers, testers, designers, and AI coding users who regularly receive Markdown documents and HTML prototypes.

## Current limitations

- Some download-only links may need to be opened through the context menu.
- JavaScript is disabled in safe HTML preview; use “Run original HTML” for interactive prototypes.
- HTML pages that depend on a multi-file project directory may need to be opened from their original location so relative assets can resolve.
- Advanced Markdown features such as Mermaid and math formulas are not included in the current build.
