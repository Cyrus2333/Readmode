隐私政策

最后更新：2026 年 8 月 25 日

Readmode 是一个 local-first Chrome 扩展，用于阅读 Markdown 文件和预览 HTML 文档、原型。当前版本不上传文档内容到 Readmode 服务器。

文档处理

用户主动导入的本地文件在浏览器中读取和渲染。用户主动选择预览在线文档时，扩展可能使用当前浏览器的登录态请求该 URL，以便访问用户本来就有权限查看的附件。文档内容不会发送到 Readmode 后端。

HTML 运行

安全预览默认限制脚本、表单、iframe 和危险 URL。用户主动选择“运行原始 HTML”后，Chrome 会按源页面规则处理脚本和外部资源；请只运行信任的文件。

本地存储

扩展使用 Chrome extension storage 保存阅读偏好、临时预览内容和（如果用户激活 Pro）本机许可证记录。临时内容用于完成当前预览，不用于建立云端文档副本。

权限

  • storage：保存偏好和临时预览数据；
  • tabs：打开阅读页并在用户选择时回到源页面；
  • contextMenus：提供在 Readmode 中打开的菜单；
  • 网站访问（HTTP、HTTPS 和用户主动允许的本地文件网址）：识别并读取用户打开的 Markdown / HTML 文档，自动渲染可以在设置中关闭。

第三方服务

当前版本不使用分析、广告追踪、文档存储或 Readmode 云端后端。未来如果接入第三方支付或许可证交付服务，会在正式启用前更新本政策，说明其处理范围。

联系我们

如需反馈隐私问题，请通过 GitHub Issues 联系维护者。请不要在公开 issue 中粘贴私人文档、凭据或许可证激活码。
