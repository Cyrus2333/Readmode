SUPPORT

帮助与反馈

本地文件打不开

请在 Chrome 扩展详情中开启“允许访问文件网址”，然后重新加载扩展并再次打开文件。也可以从 Readmode 菜单中手动导入文件。

HTML 样式不完整

安全预览会保留文档样式，但可能限制脚本、iframe、表单和危险 URL。需要交互原型时，请从 Readmode 菜单明确选择“运行原始 HTML”，并确认文件来源可信。

反馈信息

公开发布前请在此处配置正式支持邮箱或 issue tracker。提交问题时，建议附上 Chrome 版本、文件类型、是否为本地文件，以及不包含敏感内容的最小复现样例。

发布前待配置

支持邮箱、仓库地址和 Chrome Web Store 链接需要由产品负责人确认后写入此页面。
