帮助与反馈

本地文件打不开

请在 Chrome 扩展详情中开启“允许访问文件网址”，然后重新加载扩展并再次打开文件。也可以从 Readmode 菜单中手动导入文件。

HTML 样式不完整

安全预览会保留文档样式，但可能限制脚本、iframe、表单和危险 URL。需要交互原型时，请从 Readmode 菜单明确选择“运行原始 HTML”，并确认文件来源可信。

反馈信息

请通过 GitHub Issues 提交反馈。提交问题时，建议附上 Chrome 版本、文件类型、是否为本地文件，以及不包含敏感内容的最小复现样例。

提交反馈前

请先移除文档正文、客户名称、内部链接、账号信息和激活码等敏感内容，再提交到 GitHub Issues。
