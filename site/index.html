LOCAL-FIRST CHROME READER

读好 Markdown。
预览 HTML。

把本地文件、已登录的附件链接和 HTML 原型，直接变成适合人阅读和检查的 Chrome 页面。不上传文档，不再被源码淹没。

安装 Readmode了解 Pro

从 GitHub 获取 Community Edition，Chrome Web Store 版本会在上架后提供独立安装入口。

01

Markdown 阅读器

全屏布局、左侧目录、表格、任务列表、提示块、图片和代码块，让 PRD、报告和 README 更容易阅读。

02

HTML 原型预览

保留页面本身的样式和布局；默认使用安全预览，确认后再运行原始 HTML 交互。

03

本地优先

本地文档在浏览器中处理。在线链接仅在你主动打开预览时使用当前浏览器会话权限。

适合谁

产品、研发、测试、设计和 AI Coding 用户。

特别适合从 TAPD、工单系统、代码仓库或 Agent 工作流中拿到 Markdown / HTML 文件，需要快速查看而不是编辑的场景。

不做什么

不是另一个协作空间。

Readmode 不替代你的源文件系统，不上传文档，不建立评论、账号或云端项目。

NO CLOUD REQUIRED

一个阅读器，而不是另一个工作台。

基础阅读功能免费。未来 Pro 只扩展本地阅读体验，例如自定义排版和更强的文档预览能力。
