ROADMAP

先把阅读体验做好。

Readmode 当前是免费开源项目。我们会根据真实使用反馈，逐步完善本地 Markdown 阅读和 HTML 原型预览能力。

当前版本

  • 本地与已登录附件中的 Markdown 阅读
  • 保留原始布局的 HTML 安全预览
  • 用户主动选择后的原始 HTML 运行
  • 浅色 / 深色主题、目录、表格、任务列表和代码块

候选方向

  • Mermaid 与数学公式渲染
  • HTML 原型的设备尺寸预览
  • 更丰富的本地主题和代码阅读样式
  • 本地阅读记录与偏好导入导出
欢迎参与

如果你有真实的阅读场景、遇到问题或希望优先支持某个格式，请在 GitHub Issues 中提交反馈。当前没有账号、订阅或付费门槛。
