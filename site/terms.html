软件使用

Readmode 是用于在浏览器中阅读 Markdown 文件和预览 HTML 文档的 Chrome 扩展。用户应对其打开的文件、链接和 HTML 脚本负责。

HTML 原始运行

安全预览默认关闭脚本。用户主动选择运行原始 HTML 后，页面自身的脚本和外部资源可能执行；请只运行你信任的文件和来源。

未来 Pro 授权

未来 Pro 将采用一次性授权或其他明确标注的方案。许可证只用于解锁插件本地功能，不代表 Readmode 取得或保存用户文档的权利。
