项目性质

Readmode 当前以免费开源软件形式发布，源代码采用 MIT License。项目不要求账号，不提供文档云存储，也不因浏览本网站或使用扩展产生费用。

软件使用

Readmode 用于在浏览器中阅读 Markdown 文件和预览 HTML 文档。用户应对其打开的文件、链接和 HTML 脚本负责，并自行判断文件来源是否可信。

HTML 原始运行

安全预览默认关闭脚本。用户主动选择运行原始 HTML 后，页面自身的脚本和外部资源可能执行；请只运行你信任的文件和来源。
